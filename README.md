# 777 Audiovisual — Landing Page Oficial

Landing page comercial de alta conversão para a **777 Audiovisual**, produtora especializada em vídeos corporativos, captação aérea cinematográfica com drone e cobertura de feiras e congressos em São Paulo.

## 🚀 Tecnologias
- **HTML5 Semântico**
- **Tailwind CSS v4**
- **JavaScript Vanilla (ES6+)**
- **Spring Physics Animations**
- **Design Responsivo & Mobile First**

## 📐 Estrutura do Site
1. **Hero:** Showreel dinâmico em loop com headline de alto impacto e CTA para WhatsApp.
2. **Marcas:** Carrossel infinito (*marquee ticker*) com clientes corporativos e métricas de autoridade (+700 vídeos, 40+ marcas, 5M+ alcance).
3. **Serviços:** Grid 3x2 simétrico destacando Drone (UVP), Vídeo Institucional, Feiras B2B, Still de Produto, Motion/VFX e Reels.
4. **Sobre:** Composição em 2 colunas (Foto de set em alta definição + história de 5 anos e 4 pilares de garantia).
5. **Cases:** Galeria interativa com *Drawer/Sheet* lateral a 60fps apresentando desafio, solução e resultado.
6. **Bastidores:** Carrossel com fotos reais de operação em campo.
7. **FAQ:** Acordeom estratégico para eliminação de dúvidas de contratação.
8. **Contatos:** Rodapé com canais oficiais e WhatsApp flutuante persistente.

## 📦 Como Executar Localmente
Basta abrir o arquivo `index.html` em qualquer navegador ou rodar um servidor HTTP local:
```bash
python -m http.server 3000
```
Acesse em: `http://localhost:3000`
